# 숨비 (SUMBI)

> 제주 해녀의 하루를 담은 HTML5 캐주얼 잠수 게임
> 2026 미니게임 메이커스 챌린지 출품 빌드

**`index.html` 을 더블클릭하면 실행됩니다.** 서버·설치·빌드가 필요 없습니다.
소리는 브라우저 정책상 **[시작] 버튼을 누른 뒤에** 켜집니다.

> **"숨은 유한하고, 바다는 도망가지 않는다."**

채집보다 무사히 돌아오는 것이 더 중요한 게임입니다.
욕심을 부리면 망사리가 무거워지고, 무거워지면 수면이 멀어집니다.

## 1. 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | **마우스 좌클릭 드래그**(커서 방향) 또는 방향키 / WASD | **상대 드래그** (끄는 방향) |
| 상승 | Space 홀드 | 우하단 원형 버튼 홀드 |
| 채집 | 자동 — 가까이 가서 **멈추면** 홀드 게이지 | 동일 |
| 긴급 방출 | Shift | 좌하단 원형 버튼 |
| 물때 나가기 | Esc | — |

- 마우스와 키보드는 **동시 지원**입니다. 모드 전환 없이 마지막 입력이 우선합니다.
- **목표물을 클릭해서 자동으로 가는 조작은 없습니다.** 무게 저항감이 사라지고,
  이 게임에서 가장 중요한 "가다가 돌아서는 순간"이 클릭 한 번으로 축소되기 때문입니다.
- 움직이면 채집 게이지가 취소됩니다 (`HARVEST_MOVE_CANCEL` 0.35 m/s).
- **상승 입력 중에는 흡착이 작동하지 않습니다.** 귀환하려는데 붙잡히면 안 되니까요.

### 핵심 규칙

- 수면의 흰 원이 **테왁**입니다. 닿으면 망사리가 비워지고 **그만큼은 안전해집니다.**
- 숨이 다하면 죽지 않습니다. 동료 해녀가 끌어올려 주고, **잃는 것은 그때 손에 든 것뿐**입니다.
- 산소 24% 이하가 **물숨** 구간입니다. 이 구간에 딴 것은 **2.2배**를 받습니다.
  기포가 멈추고 시간이 느려지고 세상의 색이 빠집니다.
- 물때가 끝나 나오는 것은 실패가 아니므로 들고 있던 것도 챙겨 나옵니다.

## 2. 파일 구조

```
index.html            부트스트랩 + CSS + 캔버스 + HUD/UI DOM + SVG 현무암 필터(인라인)
js/config.js          CONFIG — 튜닝 단일 소스 (조명 값 포함)
js/data.js            생물 12종 · 바당 3곳 · 장비 · 살림 · 승급 · 도감 텍스트 · 대사(LINES)
js/input.js           조작 (드래그 / 터치 / 키보드)
js/audio.js           절차 생성 사운드 + 수심 연동 로우패스
js/audio-data.js      base64 SFX (현재 비어 있음 → 절차 생성으로 폴백)
js/fx.js              연출 부품 4개 + 조합 + 기포/흩어짐
js/progress.js        진행 상태 (돈 · 장비 · 살림 · 승급 · 도감 · 일차) + 저장
js/render.js          캔버스 드로잉 + 가시성 3층
js/game.js            상태 머신 · 물리 · 산소 · 채집
js/ui.js              불턱 / 도감 / 설정 / 정산 오버레이 / 디버그 패널 / 부팅
assets/img/*.png      스프라이트 (없으면 도형으로 자동 폴백)
assets/ui/*.svg       UI 아이콘
readme.md             이 문서
credits.md            에셋 출처 표
```

`<script>` 는 의존 순서대로 로드됩니다.
**config → data → input → audio → audio-data → fx → progress → render → game → ui**

## 3. 튜닝 — `js/config.js` 한 곳

값은 전부 `CONFIG` 객체 하나에 있습니다. 다른 파일에 매직넘버가 없습니다.

| 그룹 | 주요 항목 |
|---|---|
| 화면 | `VIEW_W/H`(960×600) `PIXELS_PER_METER`(40) `WORLD_WIDTH`(1400) `TIDE_DURATION`(150) |
| 산소 | `O2_MAX` `O2_DRAIN_*`(대기/이동/상승/채집) `O2_DEPTH_FACTOR` `O2_REFILL_TIME` `MULSUM_THRESHOLD` `MULSUM_BONUS` |
| 이동 | `SPEED_HORIZONTAL` `SPEED_DESCEND` `SPEED_ASCEND_BASE` |
| **무게 ★** | `WEIGHT_MAX` **`WEIGHT_ASCEND_PENALTY`** `WEIGHT_MOVE_PENALTY` `WEIGHT_SINK_BIAS` |
| 조작 | `FOLLOW_TAU_BASE/WEIGHT` `DRAG_QUADRATIC` `POINTER_FULL_DIST` `ANGLE_TURN_*` `SNAP_*` |
| 카메라 | `CHAR_HEIGHT_PCT` `CAM_ZOOM_NORMAL/DEEP/MULSUM/SURFACE` `CAM_FOLLOW_LERP` |
| 연출 | `TIMESCALE_MULSUM/ENCOUNTER/EMERGE` `SURFACE_BAND_DURATION` |
| 오디오 | `LOWPASS_SURFACE/DEEP/EMERGE_OPEN` `MASTER_VOLUME` |
| **가시성 3층** | `VIS_DEPTH_REF` `DEPTH_ATTEN_MAX` `VIS_RADIUS_*` `VIS_SOFTNESS` `LIGHT_SHAFT_*` `GLINT_*` `O2_DESAT/DARKEN` `VIGNETTE_MAX` `LANTERN_*` |

### 손대면 안 되는 값

| 값 | 이유 |
|---|---|
| **테왁 Lv2 = 8,000** | 앞 8분 안에 첫 승급이 일어나야 하는 **페이싱 제약**입니다 |
| **채집 9종 수심 순서 = 보말·미역·돌게·뿔소라·성게·오분자기·해삼·전복·문어** | 실제 서식 수심 조사 결과로 재배치했습니다. `value` 도 이 순서대로 단조 증가(200→9,000)합니다 — 문어가 가장 깊고 가장 비쌉니다 |
| **망사리 페널티 0.72 → 0.76 → 0.80** | 용량이 늘수록 페널티도 커지는 **트레이드오프가 핵심**입니다 |
| **`VIS_DEPTH_REF` = 26** | 전 스테이지 공통 절대 기준. 스테이지 최대 수심으로 나누면 12m 튜토리얼이 26m만큼 캄캄해집니다 |
| **`LANTERN_GLOW_ALPHA` = 0.18** | 랜턴은 밝히는 도구가 아니라 **색을 되돌리는 도구**입니다. 켰을 때 편안해지면 너무 밝은 것입니다 |

### 조명 튜닝 판단 기준

| 항목 | 기준 |
|---|---|
| `VIS_RADIUS_DEEP` | 심해에서 **"무섭다"가 아니라 "조심스럽다"** 가 나오는가 |
| `GLINT_ALPHA` | 0 으로 내렸을 때 심해에서 뭘 찾기가 답답해지는가. 답답하면 필요한 기능이 맞음 |
| `O2_DESAT` | 산소 저하가 수심 어둠과 **확실히 다른 감각**인가 |
| `VIGNETTE_MAX` | 높였을 때 중심부가 밝아 보이는 착시가 생기지 않는가 |
| 렌더 시간 | 2ms 이하 여유 / **8ms 초과 위험** |

**최악 조합 확인**: 최대 수심 + 산소 20% + 줌 2.0 을 동시에 걸고 화면이 완전히 죽지 않는지.

## 4. 디버그 패널

`js/config.js` 의 `DEV` 를 `true` 로 바꾸면 **`` ` `` 키**로 열립니다.

```js
DEV: true
```

- 슬라이더 30여 개 — 전부 재시작 없이 즉시 반영. **FOAM**/**SUBSURF_GLOW** 를 0으로 내리면
  근수면선의 흰 포말/발광 띠가 완전히 사라진다.
- **배경 색상 스와치** — 하늘 위/아래·먼바다(수평선~근수면선)·심해물색·안개·테왁·해녀·동료·모래·
  포말·포말 보조선·표층 발광(전역, `RENDER.COL`)과 수면 근처 바닷물색·바위색(지금 뜬 바당에만,
  `BADANG[].tint`/`rockCol`)을 색상 피커로 즉시 바꿔볼 수 있다.
  다른 바당으로 이동하면 스와치도 그 바당 색으로 따라간다. **색상 → 콘솔**로 지금 값을
  복사해 `render.js`/`data.js`에 그대로 붙여넣을 수 있고, **색상 초기화**로 패널을 연 시점
  값으로 되돌릴 수 있다(새로고침 전까지 유효).
- 실시간 통계 — fps / update ms / **render ms** / 수심 / 상승속도 / 시간상수 τ / 누적 플레이 시간
- 버튼 — 바당 즉시 이동 / 돈 +50,000 / 장비 전체 / **승급 강제** / **살림 전체 공개** / 도감 전체 / 산소 무한 / 스테이지 재생성 / **CONFIG → 콘솔** / 저장 삭제

> **`DEV = false` 이면 디버그 패널 DOM 생성과 `` ` `` 키 핸들러 등록 자체를 건너뜁니다.**
> 제출 빌드는 반드시 `false` 여야 합니다.

### 가장 먼저 볼 것

`WEIGHT_ASCEND_PENALTY` 를 **0** 과 **0.8** 로 놓고 각각 한 판씩 해보세요.
"산소가 줄어드는 긴장"보다 **"무거워서 못 올라가는 긴장"**이 더 재밌는지가 이 게임의 전제입니다.

## 5. 아트 통합

**스프라이트가 없으면 도형으로 자동 폴백됩니다.** 아트와 코드를 병렬로 진행할 수 있습니다.

`assets/img/` 에 아래 이름으로 PNG 또는 SVG 를 넣으면 자동으로 잡힙니다
(PNG 를 먼저 찾고, 없으면 같은 이름의 SVG 로 재시도합니다).

```
hae_torso  hae_head  hae_arm  hae_fin  hae_bag
cr_bomal  cr_miyeok  cr_sora  cr_seonggae  cr_haesam  cr_obunjagi
cr_munuh  cr_jeonbok  cr_dolge
ob_dolphin_body  ob_dolphin_tail  ob_turtle_body  ob_turtle_flipper  ob_ray_hub  ob_ray_wing
kelp_0  kelp_1  kelp_2        rock_0 … rock_4
bg_sky  bg_far  bg_near       tewak  bulteok
home_pot  home_books  home_field
```

- 채집 생물 9종(`cr_*`)은 통짜 이미지 한 장(512×512)입니다.
- **해녀(`hae_*`)와 관찰 3종(`ob_*`)은 지금 움직이는 관절 단위로 쪼갠 조각**입니다.
  통짜 몸 전체 이미지가 아니라 부위별 파일이며, 각 조각의 피벗(회전 기준점)과
  viewBox 규격은 `js/render.js` 의 `HAE_*` / `DOLPHIN_*` / `TURTLE_*` / `RAY_*`
  상수 주석에 정의되어 있습니다. 그 좌표계를 그대로 따라 그리면(원점·피벗 위치가
  같으면) 새 아트로 교체해도 지금의 애니메이션(발차기·팔 뻗기·지느러미 흔들림·
  날개짓)이 그대로 유지됩니다. 조각 하나가 없어도 그 부위만 벡터 도형으로 자동
  폴백되므로 부위별로 하나씩 넣어가며 확인할 수 있습니다.
  - `hae_torso`/`hae_head`(몸통/머리, 원점 기준 고정) · `hae_arm`(어깨 피벗) ·
    `hae_fin`(발목 피벗) · `hae_bag`(중심 기준, 무게만큼 스케일)
  - `ob_dolphin_body`(고정) / `ob_dolphin_tail`(꼬리 피벗)
  - `ob_turtle_body`(고정) / `ob_turtle_flipper`(앞지느러미 1장을 위·아래 관절에 재사용)
  - `ob_ray_hub`(고정) / `ob_ray_wing`(날개 1장을 위·아래 관절에 재사용)
- 오른쪽을 향한 기준 자세로 그리세요. 회전·좌우 반전은 코드가 처리합니다.
- **기울기로 산소를 표현하지 마세요.** 몸이 진행 방향으로 360도 회전하므로 읽히지 않습니다.
  산소는 **웅크림(curl, 이제는 팔/다리 관절 각도로 근사) · 발차기 진폭 · 기포 간격**으로만 전달합니다.
- 흰색 실루엣으로 만드세요. `RENDER.tint(key, color)` 가 스테이지별 색조(깊이에 따른 빛 감쇠 포함)를
  에셋 추가 없이 입혀줍니다 — 물안경 렌즈 같은 고유색 디테일은 이미지에 넣지 말고 코드가
  그 위에 덧그리는 오버레이로 남겨두세요.
- **살림은 불턱 안이 아니라 돌담 너머 "우리 집"의 변화입니다** — 굴뚝 연기(솥) /
  창 불빛(책) / 이랑 있는 밭(밭). 집·밭은 코드로 그려지므로 별도 레이어가 필요 없습니다.
- 타이틀 로고는 텍스트가 아니라 `assets/ui/title.png` 이미지 한 장입니다("숨비" + "제주 해녀의 하루" 포함, 텍스트 폴백 없음).

## 6. 사운드 넣기

앰비언스 · 심박 · 기포는 **절차 생성**이라 파일이 0개입니다 (용량 0).
효과음 7종만 `js/audio-data.js` 에 base64 로 넣으면 그 키만 녹음본이 우선합니다.

```js
var AUDIO_DATA = {
  sumbi: 'UklGRi...',   // ★ 숨비소리 — 이 게임의 로고. 반드시 직접 녹음
  harvest: '', bank: '', sell: '', upgrade: '', rank: '', fail: ''
};
```

```bash
base64 -i sumbi.wav | tr -d '\n' | pbcopy
```

> ⚠ **숨비소리를 외부 영상·다큐에서 추출하지 마세요.** 직접 녹음해야 합니다.
> `fetch` 는 `file://` 에서 차단되므로 base64 → `atob` → `decodeAudioData` 경로만 동작합니다.

### 진행 시스템

- [ ] 불턱 하단에 바당 카드 3장 상시 표시. **잠긴 것도 조건과 함께 보임**

## 8. 기술 메모 — `file://` 에서 지킨 것

심사위원이 ZIP 을 풀고 `index.html` 을 더블클릭할 것을 전제로 만들었습니다.

| 금지 | 이 빌드가 쓴 방법 |
|---|---|
| `<script type="module">`, `import`/`export` | 클래식 `<script src>` 10개 |
| `fetch()` / `XMLHttpRequest` | 데이터 전부 JS 인라인 |
| `decodeAudioData(fetch결과)` | base64 → `atob()` → `decodeAudioData` |
| `ctx.getImageData()` | 심해 색 소실을 **값 계산 + 오버레이**로 (캔버스 tainted 회피) |
| `toDataURL()` | 도감 캡처는 **캔버스 엘리먼트를 그대로** 들고 `drawImage` |
| 외부 `@font-face` | 시스템 폰트 스택 + 로고는 이미지 |
| 절대경로 / 외부 URL | 전부 `./` 상대경로 |
| 오디오 자동재생 | [시작] 버튼 안에서 `AudioContext` 생성 + `resume()` |

- `globalCompositeOperation = 'saturation'` 은 **기능 감지 후**에만 씁니다.
  미지원 브라우저에서는 대입이 조용히 실패해 회색이 화면 전체를 덮는 사고가 나기 때문에,
  감지에 실패하면 `O2_DARKEN` 만으로 폴백합니다.
- 고정 타임스텝(1/60) + delta clamp(0.10s). **물리·산소는 `dt`, 물때 타이머·산소 회복은 `dtRaw`.**
- 그라디언트는 오프스크린에 굽고 `drawImage` 로 재사용합니다 (안개 / 빛기둥 / 반짝임 / 비네트).
- localStorage 실패는 조용히 무시합니다. **저장 없이도 완전히 플레이 가능합니다.**
